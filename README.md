# 暗黑破坏神4离线数据库

这份数据库提供 S15 正式服 `3.2.1.73552` 的游戏对象、配方、三语名称与机制，也收录了 S16 测试服 `3.3.0.74145` 的战争策略、泰瑞尔的赠礼和赫拉迪姆词缀预览。

[下载 2026-11-19 离线数据库（ZIP，12.8 MB）](https://github.com/HeyDachui/diablo4-database/releases/download/v2026.11.19/diablo4-database-20261119.zip)

完整解压，再双击 `AG-暗黑4共享数据库.html`，即可用浏览器离线查询。

使用 Excel 时，打开 `AG-data/AG-exports-csv/` 中的表格。SQLite 数据库位于 `AG-data/AG-DIABLO4-SHAREABLE.sqlite3`，Python 查询示例见包内的 `AG-使用说明.md`。

[查看发布记录与文件校验值](https://github.com/HeyDachui/diablo4-database/releases)
